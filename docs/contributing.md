# Contributing

Thanks for helping LabelWise.

## Good first issues (ideas)

1. Add more UI locales (Hausa, Igbo, Yoruba, Pidgin) for result section titles.
2. Improve camera lighting / blur hints before upload.
3. Fixture pack of anonymized label photos under `public/fixtures` + a “Try sample” button.
4. Parse more NRN formats and edge cases from West African packs.
5. Soften / improve Greenbook downtime UX with retry + official links.
6. Accessibility pass: focus order, contrast, screen-reader labels.
7. Unit tests for `parseExplainJson` and `normalizeNrn`.
8. Small CSS polish for very narrow phones.

## Rules

- Do not claim a pack is fake or original from the model alone.
- Keep medical disclaimers visible.
- Never commit API keys.
